Für die Schule

Die Wand für den Beamer

Kurz gesagt: Wand-Ansicht des Klassenmodus für den Beamer: Warteansicht mit Code, Fortschritt, Ergebnis als Balken, Vollbild.

Die Wand zeigt Code, wer dabei ist und die Summen der Klasse in großer Schrift. Sie kann nichts steuern und zeigt nie, wer was gewählt hat.

So benutzen Sie die Wand

Sie öffnet sich mit einem Klick von der Seite des Klassenmodus aus.

  • Starten Sie auf Klassenmodus eine Sitzung und drücken Sie "Wand öffnen". Die Wand öffnet sich in einem neuen Tab und kennt Code und Schlüssel aus Ihrem Browser.
  • Ziehen Sie den Tab auf den Beamer und drücken Sie "Vollbild".
  • Öffnen Sie die Wand in einem anderen Browser, tragen Sie Code und Schlüssel von Hand ein. Beides steht nie in der Adresse.

Was die Wand zeigt und was nie

Sicher für den Blick der ganzen Klasse.

Wand im Überblick
PhaseDie Wand zeigtDie Wand zeigt nie
WartenAdresse, Code, Zahl der Teilnehmenden, ZufallsnamenWer sich hinter einem Namen verbirgt
Aufgabe offenFrage, Bild oder Texte, "7 von 23 haben geantwortet"Zwischenstände der Antworten
ErgebnisBalken je Antwort, richtige Antwort, ab 5 Antworten Mittelwert oder Median (nur wenn kein Feld verdeckt ist)Einzelne Antworten, verdeckte Felder, Namen
Merke

Auch die Zufallsnamen verschwinden von der Wand, sobald die erste Aufgabe läuft.

Das nimmst du mit

  • Die Wand ist nur zum Anschauen. Gesteuert wird auf der Seite des Klassenmodus.
  • Code und Schlüssel stehen nie in der Adresse.

Weiter geht es

  • Klassenmodus: gemeinsam abstimmen, ohne Namen
  • Mitmachen: Code eingeben und abstimmen
